# Qarzhy.kz — GitHub-қа салу нұсқаулығы

## 1-ҚАДАМ: Supabase (5 минут)

1. **https://supabase.com** → "Start your project" → Google аккаунтымен кір
2. "New Project" → атауы: `qarzhy` → Create
3. **SQL Editor** → `supabase_schema.sql` мазмұнын paste → **Run**
4. **Settings → API:**
   - `Project URL` → `config.js`-те `SUPABASE_URL`-ге қой
   - `anon public` кілті → `SUPABASE_KEY`-ге қой

---

## 2-ҚАДАМ: NewsAPI (2 минут)

1. **https://newsapi.org** → "Get API Key" → тіркел
2. API кілті → `config.js`-те `NEWS_API_KEY`-ге қой

---

## 3-ҚАДАМ: GitHub Desktop (10 минут)

1. **https://desktop.github.com** → жүктеп ал → орнат
2. GitHub аккаунтымен кір
3. **File → New Repository:**
   - Name: `qarzhy`
   - ✅ Initialize with README
   - → Create Repository
4. Барлық файлдарды репозиторий қалтасына көшір
5. GitHub Desktop → Summary: `Qarzhy бастапқы нұсқа` → **Commit to main**
6. **Publish repository** → жарияла

---

## 4-ҚАДАМ: GitHub Pages (3 минут)

1. github.com → репозиторийіңе кір
2. **Settings → Pages**
3. Source: `Deploy from a branch` → `main` → `/root` → **Save**
4. 2-3 минут күт →

```
https://username.github.io/qarzhy/
```

## 5-ҚАДАМ: Мазмұн енгізу

### Курс қосу
Supabase → Table Editor → `courses` → Insert row:
- `title`: Курс атауы
- `category`: basics / crypto / technical / fundamental
- `level`: beginner / intermediate / advanced
- `thumbnail_emoji`: 📊 немесе басқа emoji

### Сабақ қосу
Supabase → `lessons` → Insert row:
- `course_id`: курс ID
- `title`: сабақ атауы
- `order_num`: реті (1, 2, 3...)
- `video_url`: YouTube сілтемесі
- `pdf_url`: Google Drive PDF сілтемесі
- `content`: HTML мазмұн

### Инвестициялық идея қосу
Сайтта тіркеліп, "Идея жариялау" батырмасы арқылы.
